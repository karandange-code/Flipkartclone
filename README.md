#   Flipkart Clone

A responsive **Flipkart-inspired e-commerce website** built using **HTML, CSS, and JavaScript**.

This project was created to practice frontend development, DOM manipulation, event handling, search functionality, and basic cart interactions.

##   Features

- 🔐 Login button interaction
- 🔎 Live product search
- 🛍️ Product listing
- 🛒 Add products to cart
- 🔢 Cart item counter
- 💰 Product price calculation
- ❤️ Wishlist functionality
- 🗑️ Clear cart
- 🔔 Interactive notifications
- 📱 Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Listeners

## 🔎 Search Functionality

Users can search for products using the search bar. Products are filtered dynamically based on the entered product name.

## 🛒 Cart Functionality

Users can add products to the cart. The cart keeps track of:

- Product name
- Product price
- Quantity
- Total price

The cart counter updates automatically when products are added.

## ❤️ Wishlist

Users can add or remove products from their wishlist using the wishlist button.
